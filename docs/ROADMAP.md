## 1. Вкладка «Знаки» (спринт 1)

**Экран-галерея.** Сетка 12 карточек-созвездий; у каждой стихии свой оттенок
свечения (огонь — тёплое золото, вода — лаванда, воздух — лунно-розовый,
земля — приглушённое золото). Свой знак — первым и с отметкой «ты».
Сверху переключатель «Знаки / Совместимость».

**Профиль знака.**
- Шапка: большое созвездие, которое прорисовывается при открытии,
  с параллаксом; период, стихия, планета, камень, цвет, число.
- Разделы-«аккордеоны»: характер, сильные стороны, «тень» (мягко, без
  негатива), в любви, в дружбе, в работе, как поддержать этот знак.
- «Лучшие пары» — три знака с переходом в совместимость.
- Гороскоп на неделю/месяц — вкладками внизу (контент `weekly/{неделя}`).

**Совместимость.**
- Выбор двух знаков на «орбите»: два кольца с глифами, прокрутка пальцем.
- Анимация: два созвездия сближаются, между ними вспыхивает связь.
- Итог: общий процент + 4 кольца (любовь, дружба, работа, страсть),
  описание пары, «в чём сила / над чем работать», совет.
- 78 уникальных пар (12×13/2) — пишем отдельный контент для каждой.
- Мягкий призыв: «Узнать совместимость с реальным человеком» → вход (2.0).

**Контент:** 12 профилей + 78 пар + недельные гороскопы → JSON в
`content/`, проверка схемой, загрузка в Firestore (см. «Контент-конвейер»).

## 2. Дневник и лунный календарь (спринт 2)

**Лента по дням.** Запись = настроение + текст + теги; ответы на вопрос дня
автоматически попадают в ленту.
- Настроение — не эмодзи, а 5 фаз Луны (от новолуния «пусто» до полнолуния
  «переполняет») — в стиле приложения.
- Быстрая запись: плавающая кнопка-звезда, черновик сохраняется сам.

**Лунный календарь.** Месяц сеткой: фаза Луны на каждый день (уже считаем
офлайн), знак Луны, отметки дней с записями. Тап по дню → что было и
«что благоприятно» (мягкие лунные советы).

**Инсайты** (после 2 недель записей): «в растущую Луну ты чаще в хорошем
настроении» — лёгкая статистика по фазам. Это крючок на удержание.

**Приватность:** замок на дневник (PIN/биометрия, `local_auth`).

**Техника:** локальная база `drift` (SQLite, запросы по датам/тегам),
синхронизация с `users/{uid}/diary` по полю `updatedAt` (последняя правка
побеждает). У гостя — только локально.

## 3. Тесты и игры (спринт 3)

**Движок тестов.** Тест описывается JSON-ом: вопросы, ответы с весами
к типам результата, тексты результатов. Один экран-проигрыватель для всех
тестов → новые тесты добавляются без обновления приложения (Firestore).
- MVP: «Какая ты стихия», «Твоя звезда-хранительница»,
  «Как ты любишь — по звёздам». Ещё 2–3 — в Премиум.
- Прогресс-бар-созвездие: каждый ответ зажигает звезду.

**Карточка результата для Stories.** Экран 9:16 рендерится в PNG
(`RepaintBoundary` → `share_plus`): фон-небо, созвездие, итог, ссылка
на приложение. Та же механика — для карты дня и совместимости.

**Мини-игры:**
- **Шар судьбы** (MVP): встряхни телефон (акселерометр) → шар мутнеет,
  вибрация, проявляется ответ. Тёплые ответы, без «нет, никогда».
- **«Выбери звезду»**: на экране плавают звёзды, тап → послание дня.
- **Колесо удачи**: один спин в день (привычка), доп. спин — возможно позже за добровольный ролик
  с вознаграждением.

После результата — мягкое «Сохранить результат в аккаунте».

## 4. Профиль (спринты 4–5)

- **Данные рождения** (1.1): время + место. Поиск города — встроенная
  офлайн-база GeoNames (лицензия CC BY) + часовые пояса (`timezone`),
  чтобы правильно перевести местное время в UTC.
- **Натальная карта**: круговая схема (свой painter) — Солнце, Луна,
  асцендент бесплатно; полная карта с разбором — Премиум.
- **Уведомления**: выбор времени гороскопа дня, лунные события.
- **Подписка**: экран Премиума (RevenueCat), восстановление покупок.
- **Звёздный круг** (2.0), приватность, удаление аккаунта (уже есть).

## Сквозные улучшения

### Контент-конвейер (без платного тарифа)
1. Тексты (знаки, пары, тесты, гороскопы) — JSON в папке `content/` в git:
   история правок, ревью через PR.
2. Генерация: ИИ пишет черновик по шаблону и правилам тона → редактура →
   автоматическая проверка (длина, запрещённые «пугающие» слова, схема).
3. **GitHub Actions по расписанию** раз в сутки собирает `daily/*` на
   месяц вперёд и загружает в Firestore. Это бесплатная замена Cloud
   Functions на тарифе Spark.

### Пуши без Cloud Functions
Тот же ежедневный GitHub Actions отправляет в FCM сообщение в тему `daily`
(«Твоя карта дня ждёт ✦») через HTTP v1 API — бесплатно. Личные пуши (1.1)
по знаку — темы `sign_aries` … `sign_pisces`.

### Монетизация
- **Реклама:** в приложении нет (решение владельца). Позже возможна только добровольная награда за ролик.
- **Pro (RevenueCat), $3,99 в месяц + 6 мес./год:** личный гороскоп, полная натальная карта, подробные
  разборы совместимости, эксклюзивные тесты, личный гороскоп на неделю.
- **Remote Config** для A/B: текст пейвола, цена, момент предложения.

### Качество и доступность
- Вынести строки в `.arb` (сейчас русский в коде) → готовность к английскому.
- «Уменьшить движение» уже учитывается; добавить ручной переключатель
  «спокойная анимация» и проверку на крупном шрифте.
- Профилирование на слабом Android: при низком FPS небо переходит в
  упрощённый режим (меньше звёзд, без размытия).
- Скелетоны вместо спиннера, офлайн-баннер.

### Безопасность и запуск
- Перед публикацией: **включить принудительный App Check**, ротировать ключ
  сервисного аккаунта, отдельный аккаунт с минимальными правами для CI.
- Release-ключ подписи (upload key) — только в секретах CI, не в git.
- Firebase Hosting (бесплатно): политика конфиденциальности, условия,
  **страница удаления аккаунта** (требование Google Play).
- Возрастной рейтинг и Data Safety заполняем по списку событий аналитики
  (`lib/core/firebase/analytics.dart`).

## Процесс разработки

| Что | Сейчас | Предлагаю |
|---|---|---|
| Ветки | одна рабочая ветка | `main` защищена; фичи в ветках → Pull Request → слияние |
| Проверки | вручную в сессии | **GitHub Actions** на каждый PR: analyze, тесты, сборка APK |
| Выпуск на телефон | `tool/release.sh` из сессии | при слиянии в `main` CI сам выкладывает в App Distribution |
| Версии | вручную | `версия+номер сборки` из номера запуска CI |
| UI-регрессии | скриншоты по запросу | golden-тесты ключевых экранов; CI показывает разницу картинок |
| Устройства | ваш телефон | Firebase Test Lab — бесплатно до 10 прогонов в день |
| Ошибки | — | Crashlytics + оповещения на почту о новых падениях |
| Контент | в коде | `content/*.json` + проверка схемой в CI |

**Что нужно для CI:** добавить в GitHub → Settings → Secrets ключ
сервисного аккаунта (`FIREBASE_SERVICE_ACCOUNT`) — тогда сборки и выкладка
пойдут без моего участия.
