# «Астра» — бизнес-модель

> Статус: **предложение** — решения, отмеченные ⚠️, принимает владелец продукта.
> Границы функций и что входит в каждый релиз — в [SCOPE.md](SCOPE.md).

## 1. Суть в одном абзаце

«Астра» — бесплатное приложение-ритуал: человек открывает его каждый день ради
карты, Луны и гороскопа, ведёт дневник и делится результатами тестов.
Зарабатываем на **подписке «Астра+»** за глубину и персональность (личный
гороскоп по времени и месту рождения, натальная карта, подробная
совместимость с реальным человеком) и на **ненавязчивой рекламе** для тех,
кто не платит. Бесплатная часть остаётся щедрой — она отвечает за привычку и
сарафанное радио, платная — за доход.

## 2. Для кого и за что платят

| Сегмент | Что ищет | Готовность платить |
|---|---|---|
| **«Ритуал»** — открывает каждое утро | карта и гороскоп дня, Луна, виджет | низкая; монетизируется рекламой |
| **«Самопознание»** — дневник, тесты | понять себя, наблюдать настроение | средняя: инсайты дневника, эксклюзивные тесты |
| **«Отношения»** — совместимость | «подходим ли мы с ним» | **высокая**: персональный разбор пары по датам рождения |
| **«Глубина»** — знает свой асцендент | натальная карта, личные прогнозы | **высокая**: полная карта и личные гороскопы |

Платят за **«про меня лично»** и **«про нас двоих»**. Общие гороскопы по
знаку есть везде бесплатно — за них не платят.

## 3. Источники дохода

### 3.1. Подписка «Астра+» — основной доход (с 1.1)

| Входит | Почему за это платят |
|---|---|
| Личный гороскоп на день и неделю по натальной карте (Луна, асцендент, транзиты) | «про меня», а не «про всех Скорпионов» |
| Полная натальная карта с разбором | глубина, ради неё ставят приложение |
| Совместимость с реальным человеком по датам рождения (синастрия) | «про нас двоих» — самый сильный мотив |
| Инсайты дневника: настроение × фазы Луны, итоги месяца | ценность растёт с каждой записью |
| Эксклюзивные тесты (2–3 новых в месяц) | регулярная новизна |
| Без рекламы, темы виджета | комфорт |

**Цены (ориентир, проверяем A/B-тестом):**

| Рынок | Месяц | Год | Пробный период |
|---|---|---|---|
| Казахстан и СНГ (Google Play) | ~1 290 ₸ | ~6 990 ₸ | 7 дней |
| Россия (RuStore, см. §5) | ~249 ₽ | ~1 490 ₽ | 7 дней |
| Остальной мир (позже) | $3,99 | $24,99 | 7 дней |

Годовой план — главный (≈ 5 месяцев по цене 12), месячный — «якорь».

**Как предлагаем — без давления:**
- никогда при запуске и не в онбординге (так в концепции);
- в момент интереса: тап на «Подробный разбор» в совместимости, «Личный
  гороскоп» на «Сегодня», «Итоги месяца» в дневнике;
- одно мягкое предложение после 7-го дня использования, не чаще раза в 2 недели.

### 3.2. Реклама — для бесплатных пользователей ⚠️ (решение открыто)

| Формат | Где | Правило |
|---|---|---|
| **С вознаграждением** (основной) | доп. спин колеса удачи, доп. вопрос шару, разовый подробный разбор пары | только по желанию пользователя |
| Баннер | внизу экранов профиля знака, каталога тестов | никогда на «Сегодня», в онбординге, во время анимаций |
| Межстраничная | после 2-го пройденного теста за день | не чаще 1 раза в 5 минут |

Реклама даёт мало (СНГ — низкая стоимость показа), её задача — окупить
бесплатных пользователей и подтолкнуть к «Астра+» («без рекламы»).

### 3.3. Разовые покупки (2.0)

Для тех, кто не хочет подписку: «Полный разбор пары» (PDF/экран) ~ 199–299 ₽,
«Натальная карта с разбором» ~ 299–499 ₽, «Прогноз на год» к дню рождения.

### 3.4. Чего не делаем

- Платных «консультаций астролога», чатов с «экспертами», «снятия порчи».
- Пугающих формулировок ради продаж («узнай, что тебя ждёт, пока не поздно»).
- Тёмных паттернов: скрытой отмены, автосписаний без напоминания, пейвола на
  весь экран при запуске.

## 5. ⚠️ Платежи и реклама по рынкам — критично

По состоянию на мои данные (нужно перепроверить перед запуском):

| | Россия | Казахстан и остальной СНГ |
|---|---|---|
| Покупки через Google Play | **не работают** для российских аккаунтов с 2022 | работают |
| AdMob (реклама Google) | **показов фактически нет** с 2022 | работает |
| Альтернатива | **RuStore** (магазин + платежи VK) и **Яндекс Рекламная сеть** | — |

**Вывод:** если основная аудитория — Россия, нужен второй «контур»:
публикация в RuStore с его платёжным SDK и Яндекс-реклама. Это отдельная
работа (~1–2 недели) и отдельная сборка. Если основная аудитория — Казахстан и
СНГ, хватает Google Play + AdMob.

**Решение нужно до MVP:** какой рынок первый? (см. §9)

## 6. Юнит-экономика (иллюстрация, все цифры — допущения)

Ориентир на **10 000 активных пользователей в месяц**:

| Строка | Допущение | В месяц |
|---|---|---|
| Платящие | 2,5 % в «Астра+» | 250 человек |
| Средний чек после комиссии магазина (15 %) | ~$2,0 в мес. (смесь месяц/год) | **≈ $500** |
| Реклама | 4 000 ежедневных, 0,7 показа в день, ~$1,5 за 1 000 | **≈ $130** |
| **Выручка** | | **≈ $630** |
| Firebase (Spark → Blaze) | | $0–25 |
| Генерация контента (ИИ) | | $10–30 |
| **Маржа** | | **≈ $580** |

Рычаги: конверсия в оплату (персональные функции), удержание (виджет, пуши,
дневник), шеринг (бесплатный трафик). Платная закупка трафика — только когда
окупаемость пользователя за 90 дней выше цены установки.

## 7. Метрики

| Метрика | Цель к концу MVP-теста |
|---|---|
| Удержание D1 / D7 / D30 | 35 % / 15 % / 7 % |
| Открыли карту дня (из активных за день) | 60 % |
| Поставили виджет | 10 % |
| Поделились чем-либо (за неделю) | 8 % |
| Вошли в аккаунт | 20 % |
| Без падений (Crashlytics) | 99,5 % сессий |
| Конверсия в «Астра+» (с 1.1) | 2–3 % |

События аналитики уже собираются: `onboarding_completed`, `daily_card_flipped`,
`question_answered`, `share`, `login`, `sign_in_prompt_shown`. Для пейвола
добавим `paywall_shown`, `trial_started`, `purchase`.
