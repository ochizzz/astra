# «Астра» — концепция продукта

> Актуальные решения по тарифам, рекламе и составу релизов — в [BUSINESS_MODEL.md](BUSINESS_MODEL.md) и [SCOPE.md](SCOPE.md); при расхождении они главнее этого документа.

Мобильное приложение о зодиаке, самопознании и отношениях.

- **Аудитория:** девушки 16–35 лет.
- **Атмосфера:** таинственно, красиво, премиально.
- **Платформы:** сначала Google Play, позже App Store.

---

## 1. Стек

| Слой | Решение |
|---|---|
| Клиент | Flutter (один код для Android и iOS) |
| Архитектура | feature-first, Riverpod, go_router, тёмная тема по умолчанию |
| Бэкенд | Firebase: Auth (Google, Apple, телефон по SMS), Firestore, Cloud Functions, Cloud Messaging, Analytics, Crashlytics |
| Подписки | RevenueCat |
| Реклама | **не используется** (решение 23.11.2026; возможна позже только добровольная награда за ролик) |
| Виджет | home_widget |

## 2. Уровни доступа (вход необязателен)

| Уровень | Что доступно |
|---|---|
| **Гость** | знак по дате рождения; гороскоп / карта / цитата дня (общие); профили знаков; совместимость знаков; лунный календарь; 2–3 теста; мини-игры; дневник локально |
| **Аккаунт** (Google / Apple) | время и место рождения (асцендент, Луна); личные гороскопы; все тесты с сохранением; дневник в облаке; персональные пуши |
| **+ телефон** | друзья из контактов, «Звёздный круг», совместимость с реальными людьми |
| **Pro** («Астра+») | полная натальная карта, личные гороскопы, подробные разборы пар, эксклюзивные тесты; позже — рефлексия по дневнику. Реклама отсутствует во всех тарифах |

Правила:
- Данные гостя переносятся в аккаунт при входе (anonymous → linked account).
- **Исключение (решение владельца):** в конце онбординга — экспресс-тест, результат которого открывается по подписке «Астра+» или 7 дням бесплатно; кнопка «Не сейчас» всегда видна. Других окон при запуске нет.
- К входу зовём **мягко**: после теста, на гороскопе («уточнить по времени рождения»), в совместимости.
- **Никаких всплывающих окон при запуске.**

## 3. Навигация

**Онбординг:** дата рождения → знак → карточка «твоя карта» → (вход можно пропустить).

**5 вкладок:**

1. **Сегодня** — карта дня с анимацией переворота, цитата дня, гороскоп дня, вопрос дня, фаза Луны, шеринг в Stories.
2. **Знаки** — профили 12 знаков, психотипы, совместимость, гороскоп на неделю/месяц, натальная карта.
3. **Тесты и игры** — каталог тестов, результат-карточка для Stories, шар судьбы, «выбери звезду», колесо удачи.
4. **Дневник** — записи, настроение, ответы на вопрос дня, лунный календарь.
5. **Профиль** — вход, данные рождения, Звёздный круг, подписка, уведомления, приватность, удаление аккаунта.

## 4. Друзья из контактов (только по желанию, после входа по телефону)

```
Экран-объяснение
  → системный запрос доступа к контактам
  → номера нормализуются (E.164) и хэшируются НА УСТРОЙСТВЕ
  → Cloud Function сверяет хэши с хэшами зарегистрированных номеров
  → совпадения показываются в «Звёздном круге»
  → пуш, когда контакт регистрируется позже («твой контакт тоже здесь»)
```

- Имена и номера **на сервер не отправляются** — только хэши.
- Хэш — SHA-256 от нормализованного номера. Важно: пространство телефонных номеров мало,
  такой хэш теоретически подбирается перебором, поэтому сервер **не сохраняет** присланные
  хэши контактов (только сверяет в памяти и возвращает совпадения), функция защищена
  App Check и rate-limit, а в базе лежат лишь хэши номеров пользователей, которые сами
  включили «Звёздный круг».
- Отключение и удаление данных — в настройках.
- **Никакого** отслеживания местоположения или активности других людей.

## 5. Дизайн

| Токен | Значение |
|---|---|
| Фон | градиент `#0B0B1E` → `#2A1B4D` |
| Акцент | золото `#E8C77A` со свечением |
| Вторичный | лаванда `#B9A3F0` |
| Нежный | лунно-розовый `#F3D9E8` |
| Заголовки | Cormorant Garamond |
| Текст | Manrope |

- Тонкие золотые линейные иконки, созвездия знаков.
- Анимации: мерцание звёзд, параллакс от гироскопа, переворот карты с золотой вспышкой, проявление текста.
- Лёгкая вибрация (haptics), звук — с выключателем.

## 6. Контент

- **Никакого копирования** текстов с чужих сайтов.
- Гороскопы, цитаты, профили и тесты — свои (генерация ИИ + редактура), хранятся в Firestore.
- Тон тёплый и загадочный, **без пугающих предсказаний**.
- Пометка «для развлечения» на экранах с прогнозами.

### Астрономические расчёты и лицензии

| Библиотека | Лицензия | Вывод |
|---|---|---|
| Swiss Ephemeris (и Dart-обёртка `sweph`) | AGPL-3.0 / платная коммерческая | ❌ для закрытого кода — только с купленной лицензией |
| **Astronomy Engine** (Don Cross) | **MIT** | ✅ точность ~1′, есть JS/C/Python — подходит для Cloud Functions (натальная карта, асцендент, дома) |
| Алгоритмы Жана Миуса («Astronomical Algorithms») | формулы, не код | ✅ своя реализация фазы Луны на клиенте (офлайн, для гостя) |

**Решение:** фаза Луны и лунный календарь — локальный расчёт по Миусу в Dart
(`lib/core/astro/moon_phase.dart`). Натальная карта, асцендент, положения планет —
Cloud Function на Astronomy Engine (MIT). Swiss Ephemeris не используем.

## 7. Публикация

- Политика конфиденциальности (ссылка в сторе и в приложении).
- Форма Data Safety (Google Play).
- Удаление аккаунта в приложении **и** по веб-ссылке (требование Google Play).
- Экран-объяснение доступа к контактам (prominent disclosure).
- Вход через Apple — обязателен для iOS при наличии входа через Google.
